# Model zahrady

Veřejná, anonymizovaná kopie interaktivního plánu zahrady. Publikuje se
automaticky z privátního repa `zahrada` (skript `tools/publish_verejny_model.sh`,
workflow `.github/workflows/publish-model.yml`) — needituje se tady ručně,
změny by se přepsaly při dalším publikování.

Živá stránka: https://petranovotna.github.io/zahrada-model/
